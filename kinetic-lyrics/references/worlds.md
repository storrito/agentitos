# kinetic-lyrics: the background worlds

Over the speakers' footage the dark worlds add their light; the light ones put the footage into a frame on paper or in a studio, with dark type below. The calm ones move little and keep their motifs quiet: for most talk a calm one fits.

Stills of each world are `<skill>/assets/worlds/<world>.jpg`; copied once to `uploads/worlds/` they show in the chat as tiles.

| world | fits |
| --- | --- |
| `bokeh` | people, comedy, health |
| `noir` | crime, secrets, psychology |
| `neon` | tech, sport, speed |
| `cosmos` | big ideas, dreams |
| `aurora` | motivation, lifestyle |
| `editorial` (light) | business, education; footage in a frame |
| `geometry` (light) | products, explainers; footage in a frame |
| `slate` (calm) | news, politics, business, finance |
| `dusk` (calm) | reflection, relationships, wellbeing |
| `canopy` (calm) | nature, health, food, sport |
| `chalk` (calm) | science, education, explainers |
| `linen` (calm, light) | lifestyle, home, family; footage in a frame |
| `mist` (calm, light) | coaching, mental health, self-care; footage in a frame |

The speakers' colours: on the dark worlds light ones, `#7fe3ff #ffb36b #c9a7ff #9dffb0 #ff8fb1 #ffe066`; on the light worlds (`editorial`, `geometry`, `linen`, `mist`) dark ones, `#08609c #b0400a #5d33c4 #11703e #ad1452 #7a5c00`. A colour the other kind of world would hide is unreadable.
